## Description

A quiet place for your words. markdown is a free, open-source Markdown reader and visual editor for iPhone and iPad.

Write on a formatted page, then switch to Source to see the text underneath. Open .md and .markdown files through the native Files browser, create new documents, and save them where you choose.

• Visual editing with headings, emphasis, lists, quotes and code
• A native Markdown source editor
• Automatic saving, plus Save and Done
• Undo, redo and the iOS share sheet
• Offline editing with no account, ads or analytics
• Open source under the MIT License, by Charles Majola

Documents stay on your device or with the Files provider you select. The iOS editor blocks remote images and document links. Visual editing can normalize Markdown; use Source for custom syntax and exact text. UTF-8 files are supported.

## Review notes
No sign-in or purchase required. Tap Welcome to open a sample document, or use the native document browser to create/open UTF-8 .md/.markdown files. Visual and Source are above the editor.
