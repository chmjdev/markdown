# A little room to write

Welcome to **markdown**, your local Markdown editor for Mac.

Write here as you would in a document. Use the toolbar to add **bold**, *italic*, headings, links, lists and code. Your files stay ordinary Markdown that other apps can read.

## The essentials

- **⌘N** creates a document.
- **⌘O** opens a Markdown file.
- **⌘S** saves your changes.
- **⇧⌘S** saves a copy with a new name.
- **⌘Z** undoes your last edit.

> Switch between **WYSIWYG** and **Markdown** at the bottom whenever you want to see the source.

## Make it yours

To choose markdown as your default editor, select a `.md` file in Finder and press **⌘I**. Under **Open with**, choose **markdown**, then click **Change All…**. Repeat for `.markdown` files if you use those too.
