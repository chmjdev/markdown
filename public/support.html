A little help with markdown.

A free, open-source Markdown reader and visual editor by Charles Majola.

Contact the developer

For app issues, feedback, feature requests or privacy questions, email Charles Majola at chmjdev@gmail.com. You do not need a GitHub account to email support.

You can also report a problem on GitHub (a GitHub account is required to post). Issues are public. Include your device, OS version, app version and steps to reproduce the problem. Send a small, non-sensitive example if needed; never include credentials or private documents.

Versions and availability

Mac: version 1.0.0 is available from the Mac guide and download. Requires macOS 13 or later; the universal package includes Apple Silicon and Intel code. Runtime testing was on Apple Silicon.

iPhone and iPad: version 1.0.0 requires iOS 17 or iPadOS 17 or later. Submitted to Apple on 21 September 2026 and awaiting App Review; it is not yet available on the App Store. Initial distribution is configured outside the EU. Apple decides approval and availability.

The apps are free, with no account, subscription, in-app purchase, ads or analytics. Editing works offline; opening cloud-only files, provider sync and visiting web pages may need an internet connection.

iPhone and iPad: open, write and save

Use the + button in the Files browser to create a document, or open a .md or .markdown file. Tap Welcome for an example. Switch between Visual and Source above the page. Format offers headings, emphasis, lists, quotes and code. Changes save automatically; Save and Done also save immediately.

Use Undo and Redo to revise edits. Share sends a copy of the current text using the iOS share sheet. Files providers can sync your documents independently of markdown. Use the information button in the document browser for About, help and license notices.

Save or open problems

Download the file in Files first and confirm you have permission to edit it. Documents must be UTF-8 text. If saving fails, keep the editor open, check that the file location is available, and tap Save to retry. Share can export a copy of your current text to another available location. Confirm the copy before closing.

On Mac, use File → Open and File → Save or Save As. Mac saving is explicit: press Command-S as you work. See the Mac troubleshooting guide for file associations and other common issues.

Formatting and images

Visual editing may normalize Markdown punctuation and spacing. Raw HTML, YAML front matter, custom syntax and relative images are not guaranteed to survive visual editing unchanged. Use Source and inspect the saved result; keep backups of important documents.

The iOS editor blocks remote images and document links. Mac documents may load remote images from their original URLs. There is no built-in PDF export or app-operated cloud storage.
