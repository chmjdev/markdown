markdownSupport

A little help with markdown.

A free, open-source Markdown reader and visual editor by Charles Majola.

iPhone and iPad

Use the + button in the Files browser to create a document, or open a .md or .markdown file. Tap Welcome for an example. Switch between Visual and Source above the page. Format offers headings, emphasis, lists, quotes and code. Changes save automatically; Save and Done also save immediately.

Use Undo and Redo to revise edits. Share sends the saved document using the iOS share sheet. Files providers can sync your documents independently of markdown.

Save or open problems

Download the file in Files first and confirm you have permission to edit it. Documents must be UTF-8 text. If saving fails, keep the editor open, check that the file location is available, and tap Save to retry.

Formatting differences

Visual editing may normalize Markdown punctuation and spacing. Use Source for raw HTML, YAML front matter or custom syntax, and keep backups of important documents.

Get in touch

Report a problem or request a feature on GitHub. Include your device, OS version and steps to reproduce the problem. Do not attach sensitive documents.
